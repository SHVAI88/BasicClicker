# BasicClicker
Имеющиеся возможности:
- Имеется кнопка, при нажатии на которую считываются клики. 
- Имеются прокачки, с помощью которых можно получать больше кликов! 
- Если устали, существуют улучшения, с помощью которого клики будут приходить сами! 
- сбрасывать все клики и улучшения, для начала нового прогресса.
